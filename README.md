## Installation
 
```bash
# Exact, copy-pasteable install commands go here
git clone -b release/ipbx2026-alpha1 --single-branch https://github.com/blazestudios97/incrediblepbx-debian.git
cd incrediblepbx-debian
./install_incrediblepbx
```
